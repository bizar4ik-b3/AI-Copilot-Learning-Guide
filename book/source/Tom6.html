Додаток В. Чеклісти

В.1. Старт нового проєкту з AI

  • ☐ Git-репозиторій, гілка для експериментів
  • ☐ .editorconfig, аналізатори, nullable
  • ☐ copilot-instructions.md / AGENTS.md з командами збірки й тестів
  • ☐ CI: build + test + CodeQL/Dependabot
  • ☐ User Secrets для ключів; .gitignore перевірено
  • ☐ Захист основної гілки (PR + рев'ю)

В.2. Перед тим як прийняти код від AI

  • ☐ Прочитав diff повністю
  • ☐ Збірка без попереджень, тести зелені
  • ☐ Усі API й пакети реально існують
  • ☐ Немає секретів і зайвих залежностей
  • ☐ Безпека: вхідні дані, авторизація, SQL
  • ☐ Розумію, як це працює, і зміг би пояснити колезі

В.3. Коли якість відповіді погана

  1. Достатньо чи забагато контексту? Додайте потрібні файли / новий чат.
  2. Чіткий запит? Розділіть задачу, додайте приклади й обмеження.
  3. Є правила проєкту в інструкціях?
  4. Чи підходить модель? Спробуйте потужнішу або reasoning.
  5. Чи не застарілі знання? Додайте документацію (Learn MCP / посилання).
  6. Чи є перевірка (тести), що веде агента до правильного результату?
